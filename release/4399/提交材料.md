# 4399 提交材料包（三境守卫）

> 生成日期 2026-08-24。上传包：`tri-realm-defense-4399.zip`（8.5MB，根目录 index.html，扩展名全部符合 4399 白名单）。

## 一、游戏信息（提审填写用）

- **游戏名称**：三境守卫（备选：三国守卫战 / 塔防三境 / 守卫三境）
- **游戏类型**：H5小游戏 → 单机 / 塔防 / 策略 / 过关
- **一句话简介**：3D 塔防守城：四大世界 40 关，12 种敌人 4 大 Boss，五塔布阵守卫传送门！
- **详细简介**（可粘贴）：
  三境守卫是一款纯原创 3D 塔防游戏。翠谷草原、熔岩荒地、霜寒要塞、黄沙戈壁四大世界
  各 10 关共 40 关，难度层层递进。12 种敌人各有绝活——治疗、死亡分裂、飞行、高速突进、
  重甲推进，每个世界第 10 关还有特色 Boss（狂暴冲锋 / 死亡裂变 / 周期护盾 / 死亡召唤）。
  五座防御塔（箭塔速射、炮塔溅射、寒霜减速、特斯拉链电、狙击穿甲）均可两次升级，
  搭配出售换阵与经济运营，三星满分通关挑战你的布阵极限。骨骼动画敌人、泛光画质、
  合成音效、顿帧打击感，全部免费畅玩。
- **操作说明**：鼠标点塔坞选塔 → 点草地建造；点击已建塔升级/出售；WASD/中键拖拽平移视角，
  滚轮缩放，Q/E 旋转；Esc 暂停；⏩ 切 1x/2x/3x 倍速。
- **星级/通关目标**：每关 1-3 星（满生命通关=3星），选关界面星锁逐关解锁。

## 四、上传步骤（需要账号操作，见"找你确认"）

1. 打开 <https://open.4399.cn/console>，用 4399 账号登录/注册
2. 选择「个人开发者」，填写真实身份信息提交认证（约 2 个工作日）
3. 管理中心 → 游戏管理 → 选「H5小游戏」→ 创建游戏，填上面第一节的信息
4. 上传 `tri-realm-defense-4399.zip`，提交审核（约 1-2 个工作日）
5. 审核通过后自动发布到 www.4399.com 与 h.4399.com；平台自动挂广告 API 产生收益
6. 完善银行信息并签署开发者合同后可申请结算
