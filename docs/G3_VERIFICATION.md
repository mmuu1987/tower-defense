# G3 阶段验证报告

## 1. 阶段目标

G3 阶段实现怪物等级/等阶/词缀系统、统一波次与经济预算、召唤家族奖励、账本系统和模拟器统计。

## 2. 核心系统实现

### 2.1 敌人等级系统（enemy-stats.js）

- ✅ **等级系统**：1-100 级，基于数学模型的 HP/护甲/抗性/速度成长
- ✅ **等阶系统**：普通/精英/Boss 三个等阶，不同生命倍率和控制抗性
- ✅ **词缀系统**：5 种词缀（重甲、护盾、疾行、再生、坚韧），精英怪可携带 1-2 个词缀
- ✅ **威胁值计算**：基于耐久度、机动性、功能性的综合威胁评估
- ✅ **召唤物生成**：childProfiles() 函数处理分裂和死亡召唤，最大 1 代限制

```javascript
// 示例：生成 50 级精英重甲怪
const profile = enemyProfile('tank', { 
  enemyLevel: 50, 
  rank: 'elite', 
  affixes: ['armored'] 
});
// 结果：HP=1600, armor=9, resistance=0.12, speed=0.98, controlResistance=0.1
```

### 2.2 波次生成系统（levelgen.js）

- ✅ **统一预算模型**：每波基于威胁值预算生成敌人配置
- ✅ **经济预算**：income = bounty + clear，bounty 按权重分配给每个敌人
- ✅ **动态难度**：基于世界和关卡索引的敌人等级、数量、间隔自动调整
- ✅ **精英怪生成**：中期波次生成精英怪，后期关卡携带词缀
- ✅ **Boss 机制**：每世界第 10 关最后一波为 Boss 战

```javascript
// 生成的波次数据结构
wave: {
  groups: [
    {
      type: 'tank',
      count: 8,
      gap: 1.0,
      delay: 0.5,
      profile: { hp: 1200, armor: 8, ... },
      bounties: [45, 45, 46, 45, 46, 45, 45, 45],
      routes: [0, 1, 0, 1, 0, 1, 0, 1],
      id: 'wave-0:group-0',
      threat: 15.6
    }
  ],
  budget: { threat: 15.6, income: 360, bounty: 223, clear: 137, early: 54 }
}
```

### 2.3 经济账本系统（economy.js）

- ✅ **完整交易记录**：击杀、清波、提前开战、建造、升级、出售全记录
- ✅ **家族预算系统**：限制召唤物赏金总额，防止经济爆炸
- ✅ **余额保护**：所有支出验证余额充足，防止负数
- ✅ **重复领取保护**：每个敌人只能领取一次赏金
- ✅ **整数分配算法**：allocateBudget() 保证预算完全分配且无浮点误差
- ✅ **账本汇总**：summary() 提供分波次、分类型的收支统计

```javascript
const ledger = new EconomyLedger(500);

// 注册家族预算（限制召唤物赏金）
ledger.registerFamily('wave-0:group-0', 150, [
  { id: 'wave-0:group-0:0', amount: 50 },
  { id: 'wave-0:group-0:1', amount: 50 },
  { id: 'wave-0:group-0:2', amount: 50 },
]);

// 击杀时领取赏金
const amount = ledger.claim('wave-0:group-0', 'wave-0:group-0:0', { wave: 0, time: 5.0 });
// amount = 50，余额增加 50

// 建造塔
ledger.register({ id: 'build-1', kind: 'build', amount: -120, wave: 0, time: 2.0, tower: 'arrow' });

// 汇总统计
const summary = ledger.summary();
// { startGold: 500, balance: 430, totals: { kill: 50, build: 120 }, ... }
```

### 2.4 战斗系统集成（battle.js & entities.js）

- ✅ **波次启动**：startWave() 使用 wave.groups 的 profile/bounties/routes 数据
- ✅ **敌人生成**：spawnEnemy() 接收 profile 参数，创建带完整属性的敌人
- ✅ **敌人属性**：Enemy 构造函数使用 profile 的 hp/armor/resistance/speed/regen
- ✅ **伤害计算**：hurt() 方法使用实例属性而非定义属性
- ✅ **再生系统**：支持 profile.regen，每帧自动回血
- ✅ **治疗系统**：萨满治疗使用 profile.heal 数据
- ✅ **赏金领取**：kill() 通过账本领取赏金，自动处理家族限制
- ✅ **经济记录**：建造、升级、出售、提前开战全部记录到账本
