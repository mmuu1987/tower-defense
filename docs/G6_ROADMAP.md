## 2. 优先级任务

### P0：必须完成

#### 2.1 技能平衡调整（数值设计）
**问题**：当前技能冷却和伤害倍数基于理论设计，未经实际测试

**方案**：
1. **模拟测试**：编写 50 关全流程模拟器
   - 输入：关卡配置（敌人类型、数量、血量）
   - 输出：每座塔的技能使用次数、伤害占比、胜率
   - 工具：`tools/simulate-50-levels.mjs`

2. **收集指标**：
   - 技能释放频率（次/分钟）
   - 技能伤害占比（技能伤害 / 总伤害）
   - 冷却利用率（实际释放次数 / 理论最大次数）
   - 专精选择分布（A vs B 选择率）

3. **调整目标**：
   - 招牌技能释放频率：4-6 次/分钟
   - 技能伤害占比：25-35%（不应完全压制普攻）
   - 冷却利用率：60-80%（避免过于依赖手动释放）
   - 专精平衡：A/B 选择率差距 < 15%

**预计工作量**：5-7 天

---

#### 2.2 性能优化（低端设备）
**问题**：双层波纹 + 冲击波在多塔释放时可能影响帧率

**方案**：
1. **特效分级系统**
   ```javascript
   export const FX_QUALITY = {
     low: { rings: 1, shockwave: false, particles: 0 },
     medium: { rings: 2, shockwave: true, particles: 50 },
     high: { rings: 2, shockwave: true, particles: 100 },
   };
   ```

2. **性能检测**
   - 自动检测帧率：连续 3 秒 < 45 FPS → 降级到 medium
   - 连续 3 秒 < 30 FPS → 降级到 low
   - 用户可在设置中手动选择

3. **资源池化**
   - 波纹特效使用对象池（避免频繁创建/销毁）
   - 冲击波网格复用

**预计工作量**：3-4 天

---

#### 2.3 自动技能改进（AI 优化）
**问题**：当前自动技能优先终极，可能在无效目标上浪费

**方案**：
1. **目标价值评估**
   - 计算当前目标群的总威胁值
   - 招牌技能：威胁值 > 阈值时才释放
   - 终极技能：威胁值 > 更高阈值时才释放

2. **释放时机优化**
   - Cannon 地毯轰炸：等待 8+ 敌人进入范围
   - Tesla EMP：等待 5+ 敌人聚集
   - Sniper 标记：优先标记 Boss 和精英

3. **手动控制增强**
   - 添加 "技能保留" 模式（不自动释放终极）
   - 添加 "智能释放" 开关（启用/禁用 AI 优化）

**预计工作量**：4-5 天

#### 2.8 屏幕震动效果
**功能**：终极技能释放时震动屏幕

**实现**：
```javascript
export function screenShake(duration, intensity) {
  const camera = battle.hooks.camera;
  const start = camera.position.clone();
  const elapsed = 0;
  
  function shake(dt) {
    elapsed += dt;
    if (elapsed >= duration) {
      camera.position.copy(start);
      return;
    }
    const decay = 1 - elapsed / duration;
    camera.position.x = start.x + (Math.random() - 0.5) * intensity * decay;
    camera.position.y = start.y + (Math.random() - 0.5) * intensity * decay;
  }
  
  battle.addShakeEffect(shake, duration);
}
```
