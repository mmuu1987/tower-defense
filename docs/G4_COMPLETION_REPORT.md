## 2. 技能设计

### 2.1 炮塔（Cannon）

**定位**：对地范围伤害主力，应对密集地面单位

#### 招牌技能：集束炮击（Barrage）
- 立即发射 4 枚炮弹到当前目标位置
- 每枚造成 60% 基础伤害
- 冷却 14 秒

#### 终极技能：地毯轰炸（Carpet Bombing）
- 向目标区域发射 8 枚炮弹（3.5 格半径）
- 每枚 80% 伤害，2.5 格溅射
- 冷却 28 秒

#### 专精 A：破甲穿透
- 护甲穿透 +8
- 对精英伤害 +15%
- 对 Boss 伤害 +20%

#### 专精 B：范围增强
- 溅射半径 +25%
- 基础伤害 +12%
- 集束炮击冷却 -15%

### 2.2 狙击塔（Sniper）

**定位**：超远射程精确打击，精英/Boss 克制

#### 招牌技能：弱点狙击（Weak Spot）
- 造成 280% 伤害
- 对精英额外 +40% 伤害
- 对 Boss 额外 +60% 伤害
- 冷却 15 秒

#### 终极技能：狙击标记（Marked for Death）
- 标记目标 8 秒
- 目标受到所有来源伤害 +30%
- 狙击塔对其伤害额外 +25%
- 冷却 25 秒

#### 专精 A：穿甲弹
- 所有伤害视为真实伤害
- 弱点狙击伤害 280% → 420%

#### 专精 B：爆头
- 25% 概率造成 200% 伤害
- 攻击速度 +18%
- 弱点狙击冷却 -20%

### 2.3 电塔（Tesla）

**定位**：多目标连锁伤害，中等范围群体输出

#### 招牌技能：过载（Overload）
- 3 秒内攻击速度 +120%
- 期间每次攻击造成 85% 伤害
- 冷却 13 秒

#### 终极技能：电磁脉冲（EMP Blast）
- 4.5 格范围内所有敌人受到 150% 伤害
- 并被瘫痪（70% 减速）2.5 秒
- 冷却 27 秒

#### 专精 A：连锁增强
- 连锁目标 +4
- 连锁范围 +30%
- 过载持续时间 +1 秒

#### 专精 B：瘫痪
- 攻击附带 35% 减速，持续 1.5 秒
- 基础伤害 +15%
- 对减速目标额外 +12% 伤害

### 2.4 寒冰塔（Frost）

**定位**：范围减速控制，辅助输出

#### 招牌技能：冰环新星（Frost Nova）
- 范围 = 攻击范围 + 1.0
- 造成 80% 伤害
- 减速效果 = 当前减速 + 15%
- 持续时间 + 1.5 秒
- 冷却 12 秒

#### 终极技能：极寒领域（Blizzard Field）
- 4.0 格范围内敌人受到 200% 伤害
- 并被减速 75%，持续 6 秒
- 冷却 30 秒

#### 专精 A：深度冻结
- 减速百分比 +12%（绝对值）
- 减速持续时间 +30%
- 冰环新星减速额外 +10%

#### 专精 B：冰冻循环
- 攻击速度 +20%
- 冰环新星冷却 -25%
- 对减速目标额外 +18% 伤害

## 3. 技术实现

### 3.1 修改文件

#### `js/game/skills.js`
添加四塔的技能定义和施法逻辑：

```javascript
// 技能定义
export const SKILL_DEFS = {
  // ... 已有三塔 ...
  cannon: {
    signature: { key: 'barrage', name: '集束炮击', unlockLevel: 4, cooldown: 14 },
    ultimate: { key: 'carpetBombing', name: '地毯轰炸', unlockLevel: 8, cooldown: 28 },
    specializations: { A: {...}, B: {...} },
  },
  // ... sniper, tesla, frost ...
};

// 施法函数
function castCannon(tower, tier, ctx) { ... }
function castSniper(tower, tier, ctx) { ... }
function castTesla(tower, tier, ctx) { ... }
function castFrost(tower, tier, ctx) { ... }

// 统一调度
export function castSkill(tower, tier, ctx) {
  const casters = {
    arrow: castArrow, cannon: castCannon, sniper: castSniper,
    tesla: castTesla, frost: castFrost, venom: castVenom, beacon: castBeacon,
  };
  const ok = casters[tower.key]?.(tower, tier, ctx) ?? false;
  // ...
}
```

**关键设计决策**：
1. **立即发射 vs 延迟发射**：初版使用 `setTimeout` 实现延迟，但在测试环境中无法验证（Node.js 测试同步执行），改为立即发射多枚弹道，通过弹速差异模拟时间间隔
2. **技能复杂度平衡**：避免过于复杂的机制（如持续 DOT 场），优先使用现有系统（弹道、溅射、减速）
3. **专精修改器**：复用现有 `specializationModifiers` 系统，无需新增代码

- **Cannon**：A 偏精英克制，B 偏清场
- **Sniper**：A 极限单体，B 高频输出
- **Tesla**：A 极限群体，B 控制 + 伤害
- **Frost**：A 极限控制，B 高频输出

**验证标准**：
- 不存在明显必选分支
- 不同场景下各有优势
- 数值差异在 10-20% 范围内
