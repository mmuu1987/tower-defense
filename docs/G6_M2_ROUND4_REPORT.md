## 3. 根本问题再分析

### 3.1 为何伤害调整无效？

**G6_BALANCE_FINAL.md 的假设**（第 88-93 行）：
> 招牌技能使用频率不变，但伤害贡献降低 25%  
> 终极技能价值提升，占比从 10% → 20%

**实际结果**：
- Frost 招牌频率：28.2 → 31.4 → 35.8（**持续上升**）
- Frost 终极占比：10.8% → 11.6% → 10.3%（**未改善**）
- Tesla 终极占比：8.1% → 4.8% → 6.2%（**波动但未达标**）

**失败原因**：
1. **频率不是常数**：降低伤害不会让 AI 减少释放，因为：
   - AI 决策基于"技能是否可用"（冷却 = 0）
   - 不考虑"技能是否值得用"（伤害/收益）
2. **伤害调整无法影响释放决策**：AI 没有"伤害评估"模块
3. **冷却才是唯一杠杆**：只有延长冷却才能降低频率

### 3.2 为何冷却调整效果不稳定？

| 轮次 | Frost 冷却 | Frost 频率 | Frost 出现次数 | 单塔平均频率 |
|---|---|---|---|---|
| 基准 | 12s | 35.2/关 | 未记录 | - |
| 第一轮 | 15s | 28.2/关 | 未记录 | - |
| 第二轮 | 17s | 31.4/关 | 37 次 | 0.85/关 |
| 第四轮 | 17s | 35.8/关 | 28 次 | 1.28/关 |

**发现**：
- 第二轮：37 座 Frost 塔，每座平均 0.85 次/关
- 第四轮：28 座 Frost 塔，每座平均 1.28 次/关
- **单塔频率提升 50.6%**，说明第四轮战斗更密集或时长更长

**随机性影响**：
- 塔配置随机 → 某轮碰巧多放 Frost → 总频率虚高
- 地图随机 → 某轮路径更长 → 战斗时间更长 → 技能释放更多

**结论**：需要**固定塔配置**或**增加样本量**才能得到稳定基准。

## 5. Sniper/Cannon 伤害问题

### 5.1 Sniper 招牌技能过强

**当前配置**（[skills.js:251-256](../js/game/skills.js#L251-L256)）：
```javascript
let dmgMul = 2.2;
const mods = specializationModifiers(tower);
if (mods.signatureDamagePct) dmgMul += mods.signatureDamagePct;
if (target.def.rank === 'elite') dmgMul += 0.4;
if (target.def.shape === 'boss') dmgMul += 0.6;
```

**问题**：
- 基础 220% 伤害
- 对 Elite 可达 260%
- 对 Boss 可达 280%
- 配合 B 分支（+25%），最高可达 **305%**

**建议调整**：
```javascript
let dmgMul = 1.8;  // 220% → 180%
if (target.def.rank === 'elite') dmgMul += 0.3;  // 0.4 → 0.3
if (target.def.shape === 'boss') dmgMul += 0.4;  // 0.6 → 0.4
// 最高 180% + 30% + 40% + 25% = 275% → 降低 10.2%
```

### 5.2 Cannon 招牌技能调整

**当前配置**（[skills.js:210](../js/game/skills.js#L210)）：

const dmg = Math.round(s.dmg * 0.6);  // 每枚炮弹 60%
