## 3. 失败原因分析

### 3.1 Tesla 终极占比为何下降？

**预期逻辑**：
1. 招牌持续时间 -16.7% → 招牌价值下降
2. 招牌价值下降 → AI 更倾向使用终极
3. 终极占比应上升

**实际情况**：
1. 招牌持续时间 -16.7% → 招牌频率 -6.8%
2. 终极频率大幅下降 -41.2%（1.7 → 1.0/关）
3. 终极占比下降 -35.4%（8.2% → 5.3%）

**可能原因**：

#### 原因 1：AI 决策阈值（最可能）

**假设**：AI 判断技能是否使用的阈值是"目标数量 × 技能价值 > X"

**招牌过载价值变化**：
- 3 秒：价值 = 3 × 攻速提升 = 3 × 1.2 = 3.6
- 2.5 秒：价值 = 2.5 × 1.2 = 3.0
- 下降：-16.7%

**影响**：
- 原本勉强达到阈值的情况（3-4 个敌人）现在不达标
- Tesla 整体技能释放频率下降
- 终极技能也受影响（因为总体技能释放机会减少）

#### 原因 2：战场控制能力下降

**连锁反应**：
1. Tesla 招牌价值下降 → 使用频率下降
2. Tesla 控制能力减弱 → 敌人通过速度更快
3. 战场压力增大 → 其他塔承担更多工作
4. Tesla 参与度下降 → 终极使用机会也减少

**证据**：
- Tesla 总伤害下降 42.9%
- Cannon/Sniper 伤害上升（补偿 Tesla）
- Frost 表现改善（承担更多控制任务）

#### 原因 3：随机性影响（可能性较低）

**本轮数据异常**：
- Arrow 招牌频率异常低（10.0/关 vs 基准 12.4/关）
- Frost 终极频率异常高（2.4/关 vs 基准 1.4/关）
- 可能是随机位置配置的波动

**但**：固定配置应消除了大部分随机性

### 3.2 Frost 为何突然达标？

**Frost 数据变化**：
- 基准：终极占比 7.2%
- 第十轮：终极占比 12.5%（+73.6%）
- 终极频率：1.4 → 2.4/关（+71.4%）

**可能原因**：

#### 原因 1：Tesla 削弱后的空间释放

**理论**：
- Tesla 招牌价值下降 → 控制能力减弱
- Frost 需要承担更多控制任务
- Frost 技能使用机会增加

**证据**：
- Tesla 总伤害 -42.9%
- Frost 总伤害 +23.7%
- 职责转移

#### 原因 2：随机位置配置的幸运

**可能性**：
- 本轮 Frost 位置更优（更接近敌人路径）
- 更多触发终极的机会

**但**：固定配置下位置仍然随机

### 3.3 关键洞察：Tesla 结构性问题再现

**核心问题**：
- Tesla 招牌过载本质上是"临时攻速提升"
- 持续时间缩短 → 价值线性下降
- 但 AI 决策是非线性的（阈值效应）

**对比其他塔**：
- Arrow/Sniper/Cannon：招牌和终极都是"伤害输出"，相对独立
- Tesla：招牌影响整体战场节奏，削弱后影响全局

**结论**：
- 单纯削弱招牌持续时间不可行
- 需要重新设计 Tesla 技能机制
- 或采用方案 B（接受 5-10% 目标）
