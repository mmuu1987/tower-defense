## ❓ 常见问题

### Q1: 如何运行模拟器？

```bash
node tools/simulate-balance.mjs
```

输出文件：`balance-report.json`  
执行时间：~5 分钟

### Q2: 什么是不对称平衡策略？

为不同类型塔设定差异化目标：
- **中频输出塔**（Arrow/Sniper/Cannon）：38-43% 终极占比
- **辅助特化塔**（Beacon/Venom）：38-43% 终极占比
- **高频控制塔**（Frost/Tesla）：12-20% 终极占比

详见：[G6_BALANCE_FINAL.md](G6_BALANCE_FINAL.md)

### Q3: Tesla 为什么没有达标？

**根本原因**：招牌过载效果太强（+120% 攻速 3 秒），AI 倾向频繁释放招牌而非等待终极。

**推荐方案**：弱化招牌持续时间（3s → 2s）+ 增强终极（冷却 18s，增伤 +20%）

详见：[G6_NEXT_STEPS.md](G6_NEXT_STEPS.md)

### Q4: 第六轮为什么失败？

**原因**：同时调整 4 个参数（Frost 招牌/终极 + Tesla 招牌/终极），过度削弱 Tesla 招牌导致胜率下降至 98%。

**教训**：单次调整不超过 2 个参数，避免破坏关键技能。

详见：[G6_M3_ASYMMETRIC_BALANCE.md](G6_M3_ASYMMETRIC_BALANCE.md)
