- Round 11: 招牌过载 **3.0秒** (回滚到基准)

### 3.2 Frost稳定性验证

**核心发现**: **Frost的12.3%成功不依赖于Tesla被削弱**

**证据**:
1. Tesla恢复到3秒基准后，Frost仅下降0.2% (12.5% → 12.3%)
2. 下降幅度在随机误差范围内 (±1%)
3. Frost终极频率从2.7→2.2，但占比仍稳定在目标范围内

**结论**: 
- Frost和Tesla之间**不存在零和博弈**
- Frost的成功来自Round 7的终极增强 (冷却20s + 增伤效果)
- 可以独立处理Tesla问题，无需担心影响Frost

### 3.3 Tesla行为分析

**Round 10 (2.5s过载)**:
- 招牌: 23.7/关, 终极: 1.3/关
- 终极占比: 5.3%
- 总伤害: 10,754

**Round 11 (3.0s过载, 基准)**:
- 招牌: 17.2/关, 终极: 1.3/关
- 终极占比: 7.1%
- 总伤害: 11,152

**关键观察**:
1. **终极频率完全相同** (1.3/关) - 说明终极使用不受招牌影响
2. **招牌频率显著变化** (23.7 → 17.2) - 说明2.5s配置降低了整体参与度
3. **终极占比提升** (5.3% → 7.1%) - 但这是因为招牌下降，不是终极上升
4. **总伤害略有回升** (10,754 → 11,152) - 说明3s配置更健康

**理论验证**: Round 10的"AI决策阈值效应"理论得到证实
- 削弱招牌过载持续时间会降低Tesla整体价值
- AI判断Tesla不值得频繁使用，导致招牌和终极都受影响
- 终极占比"提升"是假象，实际是招牌下降导致的比例变化

## 5. Tesla问题根源

### 5.1 结构性问题

**招牌过载效果过强**:
- +120%攻速，持续3秒
- 相当于在3秒内打出6秒的伤害 (2.2倍效率)
- AI高度依赖这个效果，导致招牌优先级极高

**终极电磁脉冲相对较弱**:
- 冷却22秒 (招牌13秒)
- 范围4.5格 + 220%伤害 + 70%减速2.5秒
- 无额外增伤或持续效果 (与Frost、Sniper形成对比)

**AI决策阈值效应**:
- 削弱招牌 → 整体价值下降 → AI使用频率降低
- 终极频率不受冷却以外因素影响，保持在1.3/关
- 无法通过削弱招牌来"逼迫"AI更多使用终极

### 5.2 历史调整回顾

| 轮次 | 调整内容 | Tesla终极占比 | 结果 |
|---|---|---|---|
| 基准 | 无 | 8.2% | - |
| Round 8 | 3s→2s + CD 22s→18s + 增伤20% | - | 98%胜率失败 |
| Round 9 | 仅CD 22s→18s | 5.1% | 98%胜率失败 |
| Round 10 | 3s→2.5s | 5.3% | 100%胜率，但终极占比下降 |
| **Round 11** | 回滚到3s基准 | **7.1%** | 验证Frost稳定性 |

**教训**:
1. 激进削弱招牌会破坏通关稳定性 (Round 8: 3s→2s)
2. 保守削弱招牌会降低整体参与度 (Round 10: 3s→2.5s)
3. 单独缩短终极冷却在随机配置下会失败 (Round 9)
4. **参数调整难以根本解决Tesla问题**

## 6. 下一步策略

### 6.1 Option A: 组合增强终极 (推荐)

**目标**: 大幅提升终极价值，使其在AI决策中胜过招牌

**调整方案**:
```javascript
// 1. 大幅缩短终极冷却: 22s → 17s (-22.7%)
ultimate: { key: 'empBlast', name: '电磁脉冲', unlockLevel: 8, cooldown: 17 }

// 2. 增加终极增伤效果
for (const e of targets) {
  ctx.hitEnemy(e, Math.round(s.dmg * 2.2), {
    ...damageOpts(tower),
    effects: { slow: { pct: 0.7, dur: 2.5 } },
  });
  // 新增增伤debuff
  if (!e.effects) e.effects = {};
  e.effects.empVulnerable = {
    sourceTowerId: tower.id,
    until: ctx.time + 4,
    allDamagePct: 0.20,  // 受到所有伤害+20%，持续4秒
  };
}

// 3. 小幅延长招牌冷却: 13s → 15s (+15.4%)
signature: { key: 'overload', name: '过载', unlockLevel: 4, cooldown: 15 }
```

**理论基础**:
- 终极冷却-22.7% → 频率从1.3提升至1.7/关 (+30%)
- 增伤效果提升终极价值，使AI更倾向于使用终极
- 招牌冷却+15.4% → 频率从17.2降至15/关 (-13%)
- 预期终极占比: 1.7/(15+1.7) = 10.2% → 考虑增伤价值加成 → 目标12-15%

**风险评估**:
- 三参数同时调整，但幅度适中
- 招牌延长15.4%远小于Round 8的-33%
- 固定配置下100%胜率更稳定
- 可以快速回滚

### 6.2 Option B: 保守单步增强

**方案**: 仅大幅缩短终极冷却 22s → 16s (-27.3%)

**优点**:
- 单参数调整，风险最低
- 固定配置下不会出现Random配置失败问题
- 预期终极频率: 1.3 → 1.9/关 (+46%)

**缺点**:
- 不解决终极价值不足问题
- AI可能仍优先使用招牌
- 预期终极占比仅提升至11%左右，刚好达标下限

### 6.3 Option C: 接受部分成功

**方案**: 将Tesla目标降低至8-12%，接受当前7.1%接近达标

**理由**:
- 已经实现6/7塔类达标 (85.7%)
- Tesla结构性问题难以通过参数调整根本解决
- 避免过度调整破坏稳定性

**缺点**:
- 未完成7/7达标目标
- Tesla终极技能体验仍然不佳
