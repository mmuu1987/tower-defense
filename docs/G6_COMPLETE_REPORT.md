## 2. 方法论

### 2.1 自动化模拟系统

**工具**：`tools/simulate-balance.mjs`（169 行）

**核心功能**：
- 随机塔配置（每关 4-6 座塔，随机位置）
- 自动升级至 Lv.8 + 随机专精选择
- 完整战斗模拟（无头模式，~60 秒/关）
- 技能使用频率追踪
- 技能伤害贡献追踪
- JSON 报告生成

**关键代码**：
```javascript
const onSkill = (tower, tier) => {
  const key = tower.key;
  if(!stats.towers[key]) stats.towers[key] = { sig: 0, ult: 0, sigDmg: 0, ultDmg: 0, casts: 0 };
  battle._activeSkill = tier;
  if(tier === 'signature') stats.towers[key].sig++;
  else stats.towers[key].ult++;
  stats.towers[key].casts++;
};
battle.hooks.onSkill = onSkill;

// 伤害追踪
battle.hitEnemy = (enemy, damage, opts) => {
  if(opts?.sourceTowerId && battle._activeSkill) {
    const tower = battle.towers.find(t => t.id === opts.sourceTowerId);
    const key = tower.key + ':' + battle._activeSkill;
    skillDamage[key] = (skillDamage[key] || 0) + damage;
  }
  return originalHit(enemy, damage, opts);
};
```

## 6. 不对称平衡策略

### 6.1 策略理念

**核心发现**：不同类型塔的自然使用模式存在本质差异。

**传统目标的局限性**：
- 初始目标：所有塔终极技能占比 38-43%
- 现实：AOE 控制塔（Frost/Tesla）招牌技能触发条件宽松，天然高频

**新策略**：接受不对称平衡，为不同类型设定差异化标准。

### 6.2 三类塔的定位

| 类别 | 代表塔 | 定位 | 招牌频率 | 终极占比目标 |
|---|---|---|---|---|
| **中频输出** | Arrow, Sniper, Cannon | 主力输出，稳定持续伤害 | 9-16/关 | 38-43% |
| **辅助特化** | Beacon, Venom | 辅助/特化，关键时刻发力 | 10-11/关 | 38-43% |
| **高频控制** | Frost, Tesla | 战场节奏塔，频繁施放控制战局 | 24-28/关 | **12-20%** |

### 6.3 为什么不对称平衡合理

**AOE 控制塔的结构性优势**：
1. **触发条件宽松**：范围技能在任何密集波次都能命中多个目标
2. **价值感知高**：同时影响多个敌人，AI 倾向优先释放
3. **无资源成本**：只有冷却限制，无额外代价

**对比其他塔**：
- Arrow/Sniper：单体技能，需要明确高价值目标
- Cannon：溅射需要敌人聚集
- Venom：持续伤害，短期收益不明显
- Beacon：辅助增益，间接价值

**结论**：通过冷却和伤害调整无法根本改变 AOE 控制塔的使用模式，接受差异化目标更合理。

## 7. 关键技术洞察

### 7.1 冷却调整的有效性

**有效的场景**：
- 中频输出塔（Arrow/Sniper/Cannon）：冷却 ±2-3s 显著影响频率
- 单一维度调整：仅调整招牌或终极冷却

**效果有限的场景**：
- 高频控制塔（Frost/Tesla）：冷却 ±3-4s 仍有 ±15% 波动
- 同时调整招牌和终极：可能破坏相对平衡

**边际效应递减**：
- Frost 12s → 15s：频率 -19.9%（效率 0.80）
- Frost 15s → 17s：频率 +11.3%（效率 -0.87）⚠️

### 7.2 伤害调整的影响

**直接伤害削减**：✅ 非常有效
- Sniper 基础伤害 -18%：实际伤害 -31.7%
- Cannon 单发伤害 -17%：频率和伤害同时改善

**伤害再平衡**（降招牌升终极）：❌ 对 AI 无效
- AI 决策：仅基于冷却时间
- 不考虑：伤害倍率、效果持续时间

**增益效果削减**：✅ 非常有效
- Beacon 增益 -10-18%：终极占比恢复正常

### 7.3 新增机制的价值

**Frost 极寒领域增伤效果**：✅ 成功
- 增加团队协同价值
- 提升终极技能使用频率 +117%
- 不破坏游戏平衡

**可能的原因**：
- AI 判断：大范围控制 + 增伤 > 小范围招牌控制
- 终极技能价值提升，触发优先级上升

**启示**：增加额外效果（增伤/debuff）比单纯提高伤害更有效。

### 7.4 随机性的影响

**塔出现次数波动**：
- 标准差：±40%（Frost 17-37 座/50 关）
- 影响：单轮数据可能失真

**解决方案**：
1. 固定塔配置（每关 7 座塔各 1 座）
2. 增加样本量（100-150 关）
3. 多轮对比趋势（而非单轮绝对值）

## 11. 经验教训

### 11.1 成功经验

1. **数据驱动决策**：
   - 每次调整基于量化数据
   - 避免凭直觉调整（第二轮伤害调整失败的教训）

2. **迭代测试**：
   - 小步快跑（每轮 1-2 个调整）
   - 快速验证和回滚能力

3. **保持稳定性**：
   - 每次调整必须保持 100% 胜率
   - 避免破坏现有平衡（第六轮过度调整的教训）

4. **完整文档**：
   - 每轮详细记录调整原因和结果
   - 便于后续回顾和决策

### 11.2 失败教训

1. **过度调整风险**：
   - 第六轮同时调整 4 个参数导致失败
   - 教训：单次调整不超过 2 个参数

2. **随机性影响**：
   - 塔配置随机导致数据波动 ±40%
   - 教训：需要更大样本量或固定配置

3. **AI 决策局限**：
   - 伤害调整对 AI 释放决策无效
   - 教训：需要从机制层面优化（增伤/debuff）

4. **不对称平衡认知延迟**：
   - 前 4 轮追求统一标准（38-43%）
   - 第 5 轮才意识到不对称合理性
   - 教训：更早识别结构性差异

### 11.3 可改进之处

1. **固定塔配置**：
   - 当前：随机 4-6 座塔
   - 建议：每关固定 7 座塔各 1 座
   - 效果：消除 ±40% 波动

2. **增加样本量**：
   - 当前：50 关/轮
   - 建议：100-150 关/轮
   - 效果：更可靠的统计数据

3. **专精分支统计**：
   - 当前：未记录 A/B 选择
   - 建议：记录并分析专精影响
   - 效果：更细粒度的平衡调整

4. **波次分析**：
   - 当前：仅统计总频率
   - 建议：记录早期/中期/后期使用分布
   - 效果：识别不同阶段的平衡问题
