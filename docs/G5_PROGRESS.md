- ✅ 点击背景时震动提示（必须做出选择）
- ✅ 键盘可访问性（自动聚焦第一个按钮）

#### 修改器格式化支持
**百分比修改器**（自动识别 `Pct` 后缀）：
- `damagePct` → "伤害 +12%"
- `ratePct` → "攻速 +18%"
- `splashPct` → "溅射半径 +25%"
- `eliteDamagePct` → "对精英伤害 +15%"
- `bossDamagePct` → "对Boss伤害 +20%"
- `signatureCooldownPct` → "招牌技能冷却 -15%"
- `ultimateDamagePct` → "终极技能伤害 +25%"
- `slowPct` → "减速强度 +12%"
- `slowDurationPct` → "减速持续 +30%"
- `slowedDamagePct` → "对减速目标伤害 +18%"
- `poisonDamagePct` → "毒伤 +35%"
- `healBlockPct` → "治疗抑制 +35%"
- `auraDamagePct` → "光环伤害 +12%"
- `auraRatePct` → "光环攻速 +8%"
- `auraSkillCooldownPct` → "光环技能加速 +18%"

**绝对值修改器**：
- `armorPenetration: 8` → "护甲穿透 +8"
- `chains: 4` → "连锁目标 +4"
- `signatureRadius: 1.2` → "招牌技能范围 +1.2"
- `signatureDuration: 1` → "过载持续时间 +1"
- `poisonMaxStacks: 1` → "毒层上限 +1"

**布尔修改器**：
- `trueDamage: true` → "所有伤害视为真实伤害"

**对象修改器**：
- `slow: {pct: 0.35, dur: 1.5}` → "攻击附带 35% 减速 (1.5秒)"

**特殊修改器**：
- `critChance: 0.25` → "暴击几率 25%"
- `critMultiplier: 2.0` → "暴击倍率 ×2"
