## 实现清单

### ✅ 已完成

#### 1. 专精选择模态框 (Specialization Modal)
- **文件**：`js/ui/spec-modal.js` (新建)
- **功能**：
  - Lv.6 升级时自动弹出专精选择界面
  - 显示 A/B 两个分支的详细说明
  - 15+ 种修改器类型自动格式化（伤害、攻速、溅射、减速等）
  - 点击选择后自动关闭并继续升级流程
  - 自动暂停/恢复游戏逻辑
- **样式**：
  - 响应式布局（桌面 2 列，移动 1 列）
  - 深色主题，半透明背景蒙层
  - 悬停高亮效果，点击震动反馈
- **测试**：4 个测试用例，全部通过
  - 模态框创建和销毁
  - 两个分支都可选择
  - 选择回调正确触发
  - DOM 结构验证

#### 2. 技能冷却进度条 (Skill Cooldown Progress)
- **文件**：`css/style.css` (扩展)
- **功能**：
  - 径向进度条实时显示技能冷却进度
  - 冷却中：半透明白色圆环，顺时针填充
  - 就绪时：进度条淡出，按钮变绿
  - 使用 CSS 自定义属性 `--progress` 和 `--cooling`
- **实现**：
  ```css
  background: conic-gradient(#ffffff55 calc(var(--progress, 0) * 100%), transparent 0);
  ```
- **JavaScript**：在 `hud-lite.js` 的 `refreshPanel()` 中实时更新
- **性能**：使用 `toFixed(3)` 限制更新频率，避免过度重绘

#### 3. 技能音效占位系统 (Skill Audio Placeholders)
- **文件**：`js/game/audio-placeholders.js` (新建)
- **功能**：
  - 完整的技能音效 API 接口
  - 14 个音效映射（7 塔 × 2 技能）
  - 预加载进度跟踪
  - 音量控制和资源释放
- **状态**：接口完成，等待音频资源文件
- **集成点**：`battle.hooks.onSkill` 回调
- **测试**：6 个测试用例，全部通过

#### 4. 技能快捷键提示 (Skill Hotkey Labels)
- **文件**：`css/style.css` (扩展), `js/ui/hud-lite.js` (修改)
- **功能**：
  - 技能按钮右上角显示 Z/X 标签
  - 等宽字体，深色背景，灰色文字
  - 移动设备自动隐藏（< 700px）
- **样式**：
  ```html
  <kbd class="skill-key">Z</kbd>
  ```
