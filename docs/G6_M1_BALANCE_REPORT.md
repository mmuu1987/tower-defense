## 2. 数值调整方案

### 2.1 冷却时间调整

#### 调整前（G5 原始值）
| 塔 | 招牌冷却 | 终极冷却 |
|---|---|---|
| Tesla | 16s | 22s |
| Frost | 17s | 24s |
| Venom | 13s | 26s |
| Beacon | 16s | 30s |

#### 调整后（G6 M1）
| 塔 | 招牌冷却 | 终极冷却 | 变化 |
|---|---|---|---|
| Tesla | 13s | 22s | 招牌 -3s |
| Frost | 16s | 24s | 招牌 -1s |
| Venom | 13s | **22s** | 终极 -4s |
| Beacon | 16s | **25s** | 终极 -5s |

**理由**：
- Tesla/Frost 招牌技能冷却过长，导致终极技能相对更难触发
- Venom/Beacon 终极冷却过长（26-30s），远超其他塔（22-24s）

### 2.2 伤害倍率调整

#### Sniper 弱点狙击
- **调整前**：280% 基础伤害
- **调整后**：220% 基础伤害
- **理由**：技能伤害占比过高（81,760），远超其他塔

#### Sniper 狙击标记
- **调整前**：全体 +30% 伤害，狙击 +25% 额外
- **调整后**：全体 +25% 伤害，狙击 +20% 额外
- **理由**：终极技能增益过强，且持续 8 秒

#### Beacon 集结号令/超载指令
- **调整前**：招牌 +28% 伤害 +22% 攻速，终极 +55% 伤害 +42% 攻速
- **调整后**：招牌 +25% 伤害 +20% 攻速，终极 +45% 伤害 +35% 攻速
- **理由**：增益过强，且 Beacon 自身无伤害输出

## 3. 调整后验证

### 3.1 模拟结果（第二次运行）
- **胜率**：50/50 (100.0%) ✅ 保持稳定
- **技能频率改善**：
  - Frost 终极：1.7/关（调整前 2.3/关，改善有限）
  - Tesla 终极：1.3/关（调整前 2.3/关，改善有限）
  - Beacon 终极：10.0/关（调整前 15.7/关，显著改善）
  - Venom 终极：8.1/关（调整前 8.9/关，轻微改善）

### 3.2 问题分析

**Tesla/Frost 终极技能仍不活跃**：
- 根本原因：招牌技能使用频率过高（24-26 次/关），导致战斗时间短，终极技能冷却未完成
- 可能方案：
  1. 进一步缩短终极冷却（22-24s → 18-20s）
  2. 增加招牌冷却（13-16s → 18-20s）
  3. 调整 AI 优先级（优先使用终极技能）

**Cannon/Sniper 技能伤害仍然偏高**：
- Cannon 技能总伤害：99,058（招牌 85,685 + 终极 13,373）
- Sniper 技能总伤害：95,704（招牌 81,760 + 终极 13,944）
- 建议进一步降低伤害倍率或增加冷却时间
