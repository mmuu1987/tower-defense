## 实施顺序

### 阶段 1：完善现有四塔技能（优先）

目标：使 Cannon/Sniper/Tesla/Frost 达到与 Arrow/Venom/Beacon 相同的完成度。

**原因**：这四塔已有基础实现，只需扩展技能系统，可以快速验证克制关系和平衡性。

#### 1.1 炮塔（Cannon）扩展
- 扩展到 8 级
- 招牌技能（Lv.4）：集束炮击 - 短时间内发射多枚炮弹
- 专精 A（Lv.6）：破甲穿透 - 忽略部分护甲
- 专精 B（Lv.6）：范围增强 - 溅射范围扩大
- 终极技能（Lv.8）：地毯轰炸 - 大范围持续轰炸

#### 1.2 狙击塔（Sniper）扩展
- 扩展到 8 级
- 招牌技能（Lv.4）：弱点狙击 - 额外伤害精英/Boss
- 专精 A（Lv.6）：穿甲弹 - 忽略护甲
- 专精 B（Lv.6）：爆头 - 暴击机制
- 终极技能（Lv.8）：狙击标记 - 标记目标受到额外伤害

#### 1.3 电塔（Tesla）扩展
- 扩展到 8 级
- 招牌技能（Lv.4）：过载 - 短时间高频率攻击
- 专精 A（Lv.6）：连锁增强 - 更多弹跳目标
- 专精 B（Lv.6）：瘫痪 - 减速效果
- 终极技能（Lv.8）：电磁脉冲 - 范围瘫痪和持续伤害

#### 1.4 寒冰塔（Frost）扩展
- 扩展到 8 级
- 招牌技能（Lv.4）：冰环 - 范围减速和伤害
- 专精 A（Lv.6）：深度冻结 - 更强减速
- 专精 B（Lv.6）：冰冻新星 - 周期性冰环
- 终极技能（Lv.8）：极寒领域 - 持续减速场

### 阶段 3：UI 和系统集成

目标：十一塔 UI、解锁系统、存档兼容。

#### 3.1 建造菜单扩展
- 支持十一种塔的展示和选择
- 翻页或滚动机制
- 解锁状态显示
- 快捷键映射（1-9，0，-，=）

#### 3.2 解锁系统
- 按关卡进度解锁新塔
- 解锁提示和教学
- 存档记录解锁状态

#### 3.3 HUD 更新
- 升级面板支持 Lv.8
- 专精选择 UI
- 技能图标和冷却显示
- 手动技能按钮

#### 3.4 存档兼容
- 处理旧存档（五塔）迁移
- 新字段默认值
- 版本标识

### 阶段 4：克制关系和平衡

目标：建立完整的塔与敌人克制关系。

#### 4.1 克制矩阵
- 对地/对空目标类型完整
- 飞行单位克制塔（Laser/Missile 优先）
- 精英/Boss 克制塔（Sniper/Cannon 增强）
- 护甲/抗性克制（物理/法术/真实伤害）

#### 4.2 平衡调整
- 十一塔费用曲线
- 伤害/射程/攻速平衡
- 技能冷却和效果强度
- 关卡难度重新校准
