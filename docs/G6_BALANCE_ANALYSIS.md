## 2. 平衡问题

### 2.1 🔴 高频塔失衡（P0）

**Frost 和 Tesla 招牌技能使用过于频繁**

- Frost 招牌：35.2 次/关，是 Cannon 的 **4.7 倍**
- Tesla 招牌：30.4 次/关，是 Cannon 的 **4.1 倍**

**原因分析**：
1. **冷却时间过短**：Frost 12s，Tesla 13s（最短档）
2. **AOE 控制/伤害**：范围技能在密集波次中触发条件宽松
3. **无资源限制**：冷却完毕即可释放，无额外代价

**建议调整**：
- Frost 招牌冷却：12s → 15s (+25%)
- Tesla 招牌冷却：13s → 16s (+23%)
- 或：添加施法条件（需要 3+ 敌人在范围内）

### 2.2 🟡 终极技能使用率低（P1）

**Frost 和 Tesla 终极技能几乎不被使用**

- Frost 终极：2.5 次/关（仅占 6.6%）
- Tesla 终极：1.0 次/关（仅占 3.2%）

对比其他塔终极占比 38-43%，差距显著。

**原因分析**：
1. **冷却过长**：Frost 30s，Tesla 27s（最长档）
2. **收益不明显**：招牌技能已足够强，终极技能增益不足以抵消冷却代价
3. **AI 优先级**：自动施放优先招牌（冷却短、收益稳定）

**建议调整**：
- Frost 终极冷却：30s → 24s (-20%)
- Tesla 终极冷却：27s → 22s (-18%)
- 或：提升终极技能威力（范围 +20%，伤害 +30%）

### 2.3 🟢 均衡表现塔

**Arrow/Sniper/Beacon/Venom 技能分布合理**

- 招牌占比：57-62%（接近理想 60:40 分布）
- 释放频率：10-15 次/关（适中）

## 4. 推荐调整方案

### 方案 A：冷却时间调整（保守）

| 塔 | 技能 | 当前 | 建议 | 变化 |
|---|---|---|---|---|
| Frost | 招牌 | 12s | 15s | +25% |
| Frost | 终极 | 30s | 24s | -20% |
| Tesla | 招牌 | 13s | 16s | +23% |
| Tesla | 终极 | 27s | 22s | -18% |

**预期效果**：
- Frost 招牌：35.2 → 28 次/关（-20%）
- Tesla 招牌：30.4 → 24 次/关（-21%）
- Frost 终极：2.5 → 4 次/关（+60%）
- Tesla 终极：1.0 → 2 次/关（+100%）

### 方案 B：机制调整（激进）

**Frost 招牌**：
- 添加施放条件：需要范围内至少 4 个敌人
- 减速效果从固定值改为递减（首次 70%，每秒衰减 10%）

**Tesla 招牌**：
- 过载期间攻击力降低：85% → 70%
- 过载持续时间：3s → 2.5s

**终极技能通用**：
- 所有终极技能伤害 +30%
- 冷却时间统一缩短 15%

## 5. 数据洞察

### 5.1 塔类型偏好

**AOE 控制塔占主导**：
- Frost + Tesla 总释放：2060 次（占 53%）
- Cannon（AOE 伤害）：146 次（仅占 3.8%）

**原因**：
- 控制效果（减速/连锁）比纯伤害更通用
- Cannon 溅射需要敌人聚集，触发条件更严格

### 5.2 战斗时长影响

从数据样本看：
- 早期关卡（W1）：平均 80-110 秒
- 后期关卡（W5）：平均 120-180 秒

更长的战斗意味着：
- 冷却短的技能优势被放大（Frost/Tesla）
- 冷却长的技能劣势被放大（Cannon/Beacon）

### 5.3 专精分支影响

当前模拟随机选择 A/B 分支，未追踪专精对技能频率的影响。

**待验证假设**：
- Frost 专精 B（冰冻循环）：招牌冷却 -25% → 可能进一步提升使用频率
- Tesla 专精 A（连锁增强）：过载持续 +1s → 可能降低招牌需求
