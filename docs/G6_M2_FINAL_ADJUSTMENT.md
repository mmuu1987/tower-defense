## 5. 最终推荐方案

### 方案 A：接受不对称平衡（推荐）

**理念**：承认 Frost/Tesla 的角色定位不同于其他塔

**新的平衡标准**：

| 类别 | 代表塔 | 招牌频率 | 终极占比 | 定位 |
|---|---|---|---|---|
| **高频控制** | Frost, Tesla | 22-32/关 | **12-20%** | 战场节奏塔，频繁施放控制战局 |
| 中频输出 | Arrow, Sniper, Cannon | 9-15/关 | 38-43% | 主力输出，稳定持续伤害 |
| 低频辅助 | Beacon, Venom | 8-15/关 | 38-43% | 辅助/特化，关键时刻发力 |

**当前实际表现**：
- Frost：7.8%（需提升至 12-20%）
- Tesla：8.8%（接近目标下限）

**建议调整**：
1. **Tesla 终极冷却**：22s → **18s**（-18.2%）
   - 预期：2.9 → 3.5 次/关（占比 10.4%）
2. **Frost 终极冷却**：24s → **20s**（-16.7%）
   - 预期：1.8 → 2.2 次/关（占比 9.4%）
3. **Frost 终极增加额外效果**：
   - 当前：4.0 格范围，75% 减速 6 秒
   - 新增：被冰冻的敌人受到所有来源伤害 +15%（类似 Sniper 标记）

### 方案 B：固定配置验证（数据质量改进）

**问题**：当前随机配置导致数据波动 ±40%（Frost 28 → 17）

**解决**：
1. 修改 `autoPlace()` 为固定配置：
   ```javascript
   function autoPlace(battle) {
     const towers = ['arrow','cannon','sniper','tesla','frost','venom','beacon'];
     const placed = [];
     
     for(const key of towers) {
       let attempts = 0;
       while(attempts < 100) {
         attempts++;
         const cx = Math.floor(Math.random() * 42);
         const cz = Math.floor(Math.random() * 28);
         if(!battle.isBuildable(cx,cz)) continue;
         battle.selectBuild(key);
         if(battle.tryPlace(cx,cz) === true) {
           placed.push(battle.selectedTower);
           battle.gold += TOWER_DEFS[key].cost;
           break;
         }
       }
     }
     // 每关固定 7 座塔，各类型 1 座
   ```

2. 重跑 50 关，获得稳定基准
3. 消除随机性影响，清晰评估调整效果
