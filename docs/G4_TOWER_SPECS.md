# G4 塔设计规格

本文档定义四座待完善塔（Cannon/Sniper/Tesla/Frost）的完整技能设计。

## 设计原则

1. **与现有三塔对齐**：参考 Arrow/Venom/Beacon 的技能强度和冷却时间
2. **战术差异化**：每座塔有明确的战术定位，不重复
3. **专精分支清晰**：A/B 分支代表不同的升级方向，各有优势
4. **数值可调整**：初版数值作为基线，后续根据测试调整

## 炮塔（Cannon）

### 定位
- 对地范围伤害主力
- 应对密集地面单位
- 后期精英克制（配合破甲）

### 当前状态
- 基础攻击：抛物线炮弹 + 范围溅射
- 8 级数值已有（dmg 32→600, splash 1.7→3.9）
- 缺少技能系统

### 技能设计

#### 招牌技能（Lv.4）：集束炮击（Barrage）
- **效果**：0.8 秒内发射 4 枚炮弹到当前目标位置
- **伤害**：每枚 60% 基础伤害
- **冷却**：14 秒
- **用途**：快速清理密集兵群，或短时间高伤害输出

#### 专精 A（Lv.6）：破甲穿透（Armor Breaker）
- **描述**：炮弹穿透护甲，对精英和 Boss 更有效
- **效果**：
  - 护甲穿透 +8
  - 对精英伤害 +15%
  - 对 Boss 伤害 +20%
- **定位**：单体精英克制

#### 专精 B（Lv.6）：范围增强（Blast Radius）
- **描述**：溅射范围扩大，影响更多目标
- **效果**：
  - 溅射半径 +25%
  - 基础伤害 +12%
  - 集束炮击冷却 -15%
- **定位**：范围清场

#### 终极技能（Lv.8）：地毯轰炸（Carpet Bombing）
- **效果**：指定 3.5 格半径区域，持续 5 秒，每 0.6 秒落下一枚炮弹
- **伤害**：每枚 80% 基础伤害，2.5 格溅射
- **冷却**：28 秒
- **机制**：
  - 自动模式：以当前目标位置为中心
  - 手动模式：玩家指定位置（后续 UI 支持）
- **用途**：封锁路径，持续压制

## 狙击塔（Sniper）

### 定位
- 超远射程精确打击
- 精英/Boss 克制
- 单体爆发伤害

### 当前状态
- 基础攻击：超远射程穿透子弹
- 8 级数值已有（dmg 72→1080, range 6.6→10.2）
- 已有 pierce: true（无视护甲）
- 缺少技能系统

### 技能设计

#### 招牌技能（Lv.4）：弱点狙击（Weak Spot）
- **效果**：瞄准 1.5 秒后发射一枪，造成 280% 伤害
- **额外效果**：
  - 对精英额外 +40% 伤害
  - 对 Boss 额外 +60% 伤害
- **冷却**：15 秒
- **用途**：秒杀精英，重创 Boss

#### 专精 A（Lv.6）：穿甲弹（AP Rounds）
- **描述**：更强的护甲穿透和真实伤害
- **效果**：
  - 所有伤害视为真实伤害（无视护甲和抗性）
  - 弱点狙击伤害倍数 +50%（280% → 420%）
- **定位**：终极单体击杀

#### 专精 B（Lv.6）：爆头（Headshot）
- **描述**：有概率造成暴击伤害
- **效果**：
  - 25% 概率造成 200% 伤害
  - 攻击速度 +18%
  - 弱点狙击冷却 -20%
- **定位**：高频暴击输出

#### 终极技能（Lv.8）：狙击标记（Marked for Death）
- **效果**：标记一个目标 8 秒，标记期间：
  - 该目标受到所有来源伤害 +30%
  - 狙击塔对其伤害额外 +25%
- **冷却**：25 秒
- **机制**：
  - 自动模式：标记当前目标
  - 手动模式：玩家指定目标
- **用途**：团队增伤，集火高价值目标

## 电塔（Tesla）

### 定位
- 多目标连锁伤害
- 中等范围群体输出
- 配合控制（后续可加瘫痪）

### 当前状态
- 基础攻击：闪电链（3→15 个弹跳）
- 8 级数值已有（dmg 19→302, chains 3→15）
- 缺少技能系统

### 技能设计

#### 招牌技能（Lv.4）：过载（Overload）
- **效果**：3 秒内攻击速度提升 120%
- **伤害**：期间每次攻击造成 85% 伤害
- **冷却**：13 秒
- **用途**：短时间高频率清场

#### 专精 A（Lv.6）：连锁增强（Chain Master）
- **描述**：更多弹跳目标，更远弹跳距离
- **效果**：
  - 连锁目标 +4
  - 连锁范围 +30%
  - 过载持续时间 +1 秒
- **定位**：极限群体输出

#### 专精 B（Lv.6）：瘫痪（Paralyze）
- **描述**：电击附带减速效果
- **效果**：
  - 攻击附带 35% 减速，持续 1.5 秒
  - 基础伤害 +15%
  - 对减速目标额外 +12% 伤害
- **定位**：控制 + 伤害

#### 终极技能（Lv.8）：电磁脉冲（EMP Blast）
- **效果**：释放电磁脉冲：
  - 4.5 格范围内所有敌人受到 150% 伤害
  - 并被瘫痪（70% 减速）2.5 秒
- **冷却**：27 秒
- **机制**：以电塔为中心
- **用途**：范围控制 + 伤害

## 寒冰塔（Frost）

### 定位
- 范围减速控制
- 辅助输出
- 克制高速单位

### 当前状态
- 基础攻击：冰环脉冲（范围减速 + 伤害）
- 8 级数值已有（dmg 10→210, slow 48%→87%）
- slow.dur 2.0→4.5 秒
- 缺少技能系统

### 技能设计

#### 招牌技能（Lv.4）：冰环新星（Frost Nova）
- **效果**：释放冰环：
  - 范围 = 攻击范围 + 1.0
  - 造成 80% 伤害
  - 减速效果 = 当前减速 + 15%
  - 持续时间 + 1.5 秒
- **冷却**：12 秒
- **用途**：扩大控制范围，增强减速

#### 专精 A（Lv.6）：深度冻结（Deep Freeze）
- **描述**：更强的减速效果
- **效果**：
  - 减速百分比 +12%（绝对值）
  - 减速持续时间 +30%
  - 冰环新星减速额外 +10%
- **定位**：极限控制

#### 专精 B（Lv.6）：冰冻循环（Frozen Cycle）
- **描述**：更频繁的冰环释放
- **效果**：
  - 攻击速度 +20%
  - 冰环新星冷却 -25%
  - 对减速目标额外 +18% 伤害
- **定位**：高频控制 + 输出

#### 终极技能（Lv.8）：极寒领域（Blizzard Field）
- **效果**：创建 4.0 格半径冰场，持续 6 秒：
  - 范围内敌人持续受到每秒 35% 伤害
  - 并被减速 75%
  - 每 0.8 秒触发一次伤害和减速刷新
- **冷却**：30 秒
- **机制**：
  - 自动模式：以当前目标位置为中心
  - 手动模式：玩家指定位置
- **用途**：封锁路径，持续控制

## 实现优先级

### 第一批（快速验证）
1. **Cannon** - 最简单，只需要追踪弹道和溅射
2. **Tesla** - 利用现有连锁系统

### 第二批（控制机制）
3. **Frost** - 利用现有减速系统
4. **Sniper** - 需要标记系统（新机制）

## 技能实现清单

每座塔需要在 `skills.js` 中添加：

```javascript
{
  signature: { key: 'xxx', name: 'xxx', unlockLevel: 4, cooldown: XX },
  ultimate: { key: 'xxx', name: 'xxx', unlockLevel: 8, cooldown: XX },
  specializations: {
    A: { key: 'xxx', name: 'xxx', desc: 'xxx', modifiers: { ... } },
    B: { key: 'xxx', name: 'xxx', desc: 'xxx', modifiers: { ... } },
  },
}
```

以及对应的 `castXxx()` 函数实现技能逻辑。
